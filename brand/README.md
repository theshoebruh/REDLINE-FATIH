# Brand

Identity assets and decisions.

```
logo/       RF mark — dark, white (transparent) and red variants
fonts/      typography roles and licensing notes
colours/    palette intent + rules
references/ moodboard and photography direction
```

The mark is a placeholder: a red square with RF set in the display face. It exists so
nothing in the build references a missing file. Replace all three SVGs together, keep
the filenames, and the site picks them up (the header reads
`website/public/images/brand/RF-logo-red.svg`).
